# Logos — dossier projet

Logos versionnés avec le code source :

| Fichier | Usage |
|---------|--------|
| `app-logo.svg` | Identité Hotel Metrics Pro (sidebar, login) |
| `default-hotel.svg` | Placeholder quand un hôtel n'a pas de logo |

À l'exécution, ces fichiers sont copiés dans le dossier applicatif :

`%AppData%/Hotel Metrics Pro Desktop/data/logos/assets/`

Les logos des hôtels sont enregistrés dans :

`%AppData%/Hotel Metrics Pro Desktop/data/logos/hotels/{uuid}.png`
